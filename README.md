# POUTNÍK KOKPIT

Provozní dashboard půjčovny expedičních vozů (poutnik.lovable.app).
Živě: **https://frantisekdron.github.io/poutnik-kokpit/** · demo: `?demo=1`

- Data: privátní repo `frantisekdron/poutnik-data` (zápis přes GitHub API, každá změna = commit)
- Přístup: `python3 nastav_pristup.py` (jemný PAT jen na poutnik-data, zašifrovaný heslem)
- Nasazení změn: `./nasadit.sh "co se změnilo"`
- Plán, role a nákupní seznam GPS: viz PLAN.md
